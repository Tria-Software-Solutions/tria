## Inglés / English

### Brand Essence
**Building Software That Matters.** tria is a Costa Rican software engineering company — precision, quality, and partnership in everything we build.

### Logo
- **Wordmark:** "tria" in lowercase, using the display font (Outfit), with an accent-colored dot: **tria<span style="color:#068e8c;">.</span>**
- Clear space: keep at least the height of the "t" on all sides.
- Minimum size: 24px (screen) / 10mm (print).
- Do not: stretch, rotate, add effects, or place on busy backgrounds without contrast.

### Color Palette
| Token | Hex | Usage |
|-------|-----|-------|
| Ink / Primary text | `#0b0d17` | Headings, body on light |
| Accent (teal) | `#068e8c` | CTAs, links, highlights, the logo dot |
| Accent dark | `#057573` | Accent hover |
| White | `#ffffff` | Backgrounds, text on dark |
| Paper gray | `#f5f7f9` | Alternate section backgrounds |
| Text secondary | `rgba(0,0,0,0.5–0.6)` | Body copy on light |
| Text on dark | `rgba(255,255,255,0.4–0.6)` | Body copy on dark |

### Typography
- **Display / Headings:** Outfit (weights 200–600; thin weights for contrast)
- **Body:** Outfit (or system fallback) — weights 380–450
- Hierarchy: suptitle (uppercase, letter-spacing 0.12–0.16em) → title (thin/light, tight tracking) → body
- The "thin" treatment (`tria-thin`, weight 200) is used inside titles for the contrasting word.

### Tone of Voice
- Clear, confident, human.
- Bilingual by default (EN + ES) for client-facing materials.
- Avoid hype; prefer specific outcomes ("moves your metrics", "ships with confidence").

### Imagery
- Modern, minimal, generous whitespace.
- Dark sections (`#0b0d17`) with teal accents and subtle glows/ambient gradients.
- Rounded cards (16–24px radius), soft shadows.

### Do / Don't
- ✅ Use lowercase "tria", the teal dot, and thin typography.
- ✅ Use the accent for the single most important action.
- ❌ Never write "Tria Software Solutions" as the logo wordmark.
- ❌ Never use bright saturated colors other than the accent.
- ❌ Never crowd the frame — whitespace is part of the brand.

## Español / Spanish

### Esencia de Marca
**Construyendo Software Que Importa.** tria es una empresa costarricense de ingeniería de software — precisión, calidad y alianza en todo lo que construimos.

### Logo
- **Wordmark:** "tria" en minúsculas, con la fuente display (Outfit) y un punto en color acento: **tria<span style="color:#068e8c;">.</span>**
- Espacio de seguridad: al menos la altura de la "t" en todos los lados.
- Tamaño mínimo: 24px (pantalla) / 10mm (impresión).
- No: estirar, rotar, añadir efectos ni colocar sobre fondos recargados sin contraste.

### Paleta de Colores
| Token | Hex | Uso |
|-------|-----|-----|
| Ink / Texto principal | `#0b0d17` | Títulos, cuerpo en claro |
| Acento (teal) | `#068e8c` | CTAs, links, highlights, el punto del logo |
| Acento oscuro | `#057573` | Hover del acento |
| Blanco | `#ffffff` | Fondos, texto sobre oscuro |
| Gris papel | `#f5f7f9` | Fondos de sección alternos |
| Texto secundario | `rgba(0,0,0,0.5–0.6)` | Texto de cuerpo en claro |
| Texto sobre oscuro | `rgba(255,255,255,0.4–0.6)` | Texto de cuerpo sobre oscuro |

### Tipografía
- **Display / Títulos:** Outfit (pesos 200–600; pesos finos para contraste)
- **Cuerpo:** Outfit (o fallback de sistema) — pesos 380–450
- Jerarquía: suptitle (mayúsculas, letter-spacing 0.12–0.16em) → título (fino, tracking ajustado) → cuerpo
- El tratamiento "thin" (`tria-thin`, peso 200) se usa dentro de los títulos para la palabra de contraste.

### Tono de Voz
- Claro, seguro, humano.
- Bilingüe por defecto (EN + ES) en materiales para clientes.
- Evita el hype; prefiere resultados específicos ("mueve tus métricas", "entrega con confianza").

### Imágenes
- Modernas, minimalistas, con espacio en blanco generoso.
- Secciones oscuras (`#0b0d17`) con acentos teal y glows/gradientes ambientales sutiles.
- Tarjetas redondeadas (16–24px de radio), sombras suaves.

### Sí / No
- ✅ Usa "tria" en minúsculas, el punto teal y la tipografía fina.
- ✅ Usa el acento para la única acción más importante.
- ❌ Nunca escribas "Tria Software Solutions" como wordmark del logo.
- ❌ Nunca uses colores saturados brillantes fuera del acento.
- ❌ Nunca satures el frame — el espacio en blanco es parte de la marca.
