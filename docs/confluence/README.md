## Cómo subir a Confluence / How to import into Confluence

1. Crea un **espacio** nuevo en Confluence (por ejemplo: `TRIA` — Corporate Docs).
2. Crea una **página raíz** con el índice (copiar este archivo).
3. Para cada documento: *Create → Page* y pega el contenido de `## Inglés / English` y `## Español / Spanish` (o crea una página por idioma).
4. Con Markdown: usa *Import → From Markdown* para preservar tablas y encabezados, o pega directamente y usa el *Markdown macro*.

> 💡 **Tip de membrete**: el archivo [_membrete.md](_membrete.md) contiene el bloque de cabecera oficial (logo, contacto, dirección). Pégalo al inicio de toda página antes de compartirla externamente.
